# Contribuer

1. Ouvrez une issue décrivant le problème ou l'amélioration.
2. Reproduisez le problème avec une position ou une commande précise.
3. Gardez les dépendances externes facultatives et documentées.
4. Lancez `python -m py_compile Pandoraga.py` avant une pull request.
5. Pour les changements du moteur, ajoutez des tests de règles d'échecs et indiquez les résultats mesurés.
6. Ne publiez aucune mémoire JSON personnelle, clé, donnée privée ou exécutable Stockfish propriétaire.

Les contributions ne doivent pas annoncer de niveau Elo sans mesure reproductible.
